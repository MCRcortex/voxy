# NeoVoxy NeoForge 1.21.1

> **Unofficial NeoForge port** of Voxy / NeoVoxy.
>
> This is **not an official port** and is **not supported, maintained, or endorsed by Cortex / MCRcortex**.

## About

NeoVoxy is a Level-of-Detail (LOD) rendering mod for Minecraft. It renders distant terrain at lower detail levels to extend the visible view distance beyond vanilla rendering.

This repository contains a native NeoForge port maintained by **EyeCrasher**.
